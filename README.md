# シャーリング取り合わせツール

製品寸法・数量から大板の長さ・枚数を計算するWindowsアプリです。

## ダウンロード

- [最新版アプリ・説明書](https://github.com/tsuyo39-glitch/shearing-tool/releases/latest)
- [操作説明書PDF（6ページ）](https://github.com/tsuyo39-glitch/shearing-tool/releases/latest/download/user-guide.pdf)
- [リポジトリ内の説明書](docs/user-guide.pdf)

利用者用EXEは `shearing-tool-windows.exe` です。Pythonは不要です。初回はPC専用のlicense.datを読み込みます。[ライセンス登録手順](LICENSE_GUIDE.md)

## 基本操作

1. 大板幅・最大長さ・ロス・切断代・長さ丸めを設定します。
2. 製品名・規格・板厚・幅・長さ・必要枚数を入力し、目付（めっき）を選択します。規格は自由入力です。
3. 「長さ・枚数を計算」を押し、数量・歩留り・重量・図を確認します。
4. 「Excel出力（図解付き）」で選択した候補を保存します。

規格・板厚・目付が違う製品は混載しません。幅ロスは片側、長さロスは前後各です。重量は母材板厚×7.85に登録のめっき量定数kg/㎡を加算します。板厚が未入力の場合、合計重量は未計算です。

電気亜鉛・合金化溶融亜鉛（F）・10/10等の表裏表記を選択できます。標準付着量と計算用定数は区別しています。マスタの確認済み設定と削除は「編集」メニュー内にあり、削除前に1回確認します。「保存して閉じる」で反映します。

製品の登録、案件JSON保存・読み込みに対応します。「Excelから貼り付け」ボタンはありません。入力変更後は再計算してください。青い境界を上下にドラッグして製品欄の高さを変更できます。

## 更新とデータ保管

アプリを終了してEXEを置き換えます。登録データ・案件データ・計算結果とlicense.datは残してください。旧マスタの移行時は日時付きバックアップを作成します。別PCにはそのPC用ライセンスが必要です。
