# シャーリング取り合わせツール

製品寸法と必要枚数から、大板の必要長さ・枚数、歩留り、取り合わせ図を計算するWindows用アプリです。

## ダウンロード

- [最新版リリース（アプリ・説明書）](https://github.com/tsuyo39-glitch/shearing-tool/releases/latest)
- [スクリーンショット付き操作説明書PDF（10ページ）](https://github.com/tsuyo39-glitch/shearing-tool/releases/latest/download/user-guide.pdf)
- [リポジトリ内で説明書を表示](docs/user-guide.pdf)

説明書は初回ライセンス登録、大板条件、製品入力、計算結果、製品登録、案件JSON、Excel貼り付け・出力、バックアップを順に説明しています。

[最新版のWindows EXE](https://github.com/tsuyo39-glitch/shearing-tool/releases/latest)から `shearing-tool-windows.exe` を保存して起動してください。Pythonのインストールは不要です。

**利用PC専用のライセンスが必要です（現行の発行ライセンスは無期限）。** 初回起動時にHWIDを発行者へ伝え、受け取った `license.dat` を読み込んでください。期限更新・オンライン認証はありません。既存のライセンスがある場合はEXE横に残して更新してください。

発行者専用ツールはリリースに含めません。[利用者の登録手順](LICENSE_GUIDE.md)
書き込み可能なフォルダーに置いてください。更新時はアプリを終了してEXEを置き換え、データフォルダーは残してください。

## 主な機能

- 大板幅と最大長さから必要な大板長さ・枚数を自動計算
- 幅・長さロスと製品間切断代の設定・自動保存
- 製品ごとの90度回転可否、規格・板厚別の配置
- 製品の登録・検索・呼び出し・更新・削除
- 案件単位の保存・読込、未保存変更の確認
- Excelから製品一覧を貼り付け、取込前プレビューとエラー表示
- 入力変更後の再計算通知と古い計算結果のExcel出力防止
- 結果一覧と、全パターンをA4横1ページにまとめた図解一覧のExcel出力

## 表示範囲の調整

製品欄は初期高さ200pxです。製品欄と計算ボタンの間の青い境界を上下にドラッグして、製品一覧の高さを調整できます。右端スクロールはそのまま使用できます。ウインドウの端・角をドラッグすると全体のサイズも変わります。最大化中は一度「元に戻す」を押してください。

## 基本操作

1. 大板幅・最大長さ・ロス・切断代を設定します。
2. 製品名・幅・長さ・必要枚数を入力します。規格・板厚は任意です。
3. 「長さ・枚数を計算」を押します。
4. 候補を選び、必要大板数・寸法別内訳・取り合わせ図を確認します。
5. 「Excel出力（図解付き）」で選択した候補を保存します。

入力変更後は再計算してください。前回の結果が表示されていてもExcel出力は無効です。計算中に変更した場合や中止した場合も再計算が必要です。

## 案件保存・読込

画面上部の「案件を保存」で、案件名・得意先・備考・大板条件・全製品をJSON保存します。案件名は必須です。
案件名・得意先・備考は画面上部の「情報編集」で編集できます。確定後に「案件を保存」でファイルへ保存してください。
「案件を開く」で復元後、再計算してください。計算結果自体は保存しません。
未保存の変更がある場合、読込・終了時に保存／破棄／キャンセルを選べます。不正ファイルは入力へ反映しません。

## Excelから貼り付け

次の列順でセル範囲をコピーし「Excelから貼り付け」を押してください。

| 製品名 | 規格 | 板厚 | 幅 | 長さ | 必要枚数 | 回転可否 |
|---|---|---|---|---|---|---|
| 製品A | SPCC | 1.2 | 155 | 1219 | 124 | 不可 |

- 見出し行は任意です。列順は固定です。
- 製品名・規格・板厚・回転可否は空欄でも取り込めます。
- 幅・長さは正の数、必要枚数は正の整数です。
- 回転可否は「可／不可」「TRUE／FALSE」「1／0」。空欄・列省略時は「可」です。
- 全角数字に対応します。単位はmm、数値セルに単位文字を含めないでください。
- プレビューの「一覧へ追加」で既存製品に追加します。不正行がある場合は追加できません。元のExcelを修正してコピーし直してください。

## ロスと計算仕様

| 項目 | 初期値・意味 |
|---|---|
| 大板幅 | 1219mm、変更可能 |
| 最大大板長さ | 画面初期1219mm、変更可能 |
| 幅ロス | 10mm、片側のみ |
| 長さロス | 0mm、前後それぞれに適用 |
| 製品間切断代 | 0mm |

- 有効幅＝大板幅－幅ロス。幅1219mm・幅ロス10mmなら1209mm。
- 有効最大長さ＝最大大板長さ－長さロス×2。
- 算出大板長さ＝有効領域内の配置最下端＋長さロス×2。
- 歩留り＝製品総面積÷投入大板総面積×100。
- 規格・板厚が異なる製品を混載しません。板厚未指定も指定済みとは分けます。
- 必要枚数どおりに配置します。数量充足、投入面積、枚数の順で候補を表示します。
- 探索時間は最大10秒、製品合計20,000枚以内です。最適解の保証はありません。

例：大板1219×1219mm、幅ロス10mm、長さロス0mm、切断代0mmなら、155×1219mmを1枚の大板から7枚採取できます。

## データの保存場所とバックアップ

EXEと同じフォルダーに作成されます。

| フォルダー | 内容 |
|---|---|
| 登録データ | 製品登録、最後に入力した有効なロス・切断代 |
| 案件データ | 案件JSONの初期保存先 |
| 計算結果 | Excelの初期保存先 |

別のPCへ移すときは、EXEと上記フォルダーをコピーし、移行先PC用のライセンスを発行してください。他のPCのlicense.datは使用できません。個別データはこのリポジトリに含めていません。
