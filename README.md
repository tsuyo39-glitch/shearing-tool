# Shearing Tool

Windows向けシャーリング取り合わせツール。製品寸法と必要枚数から、大板の必要長さ・枚数と配置候補を計算します。

## 主な機能

- 大板幅・最大長さの画面初期値は1219mm。変更可能。
- 幅ロスは片側のみ（初期10mm）。有効幅＝大板幅－幅ロス。
- 長さロスは前後各（初期0mm）。有効最大長さ＝最大長さ－前後各ロス×2。
- 幅・長さロスと切断代は最後の有効値を保存し、次回復元。
- 製品登録・検索・呼び出し、製品ごとの90度回転設定。
- 規格・板厚別に配置。必要枚数・歩留り・取り合わせ図を表示。
- Excel出力：結果一覧と、全パターンをA4横1ページにまとめた図解一覧。

## 起動

Releasesの `shearing-tool-windows.exe` をダウンロードして起動します。
登録データはEXE横の「登録データ」、出力先の初期値は「計算結果」です。
更新時はEXEを置き換え、登録データは残してください。別PCへ移す場合は登録データも一緒にコピーしてください。

## ソースから実行

```sh
python -m pip install -r requirements.txt
python app_auto_length.py
```

ビルドは `build_auto_length.bat`、検証は `python -m unittest discover -s tests`。
`app.py` は従来の固定大板版です。

## 計算仕様

大板長さ＝有効領域内の配置最下端＋前後各ロス×2。
歩留り＝製品総面積÷投入大板総面積×100。
探索候補は数量充足を優先し、投入面積、枚数の順に表示します。最適解の保証はありません。
最大計算時間は10秒、製品合計は20,000枚以内です。図解は配置の説明であり、実際の切断順序は設備条件に合わせて確認してください。
